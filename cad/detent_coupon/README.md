# Zero-detent calibration rig

Compact rig using the exact v5 cam track and replaceable detent cassette geometry.

Print:
- 1x detent_coupon_base
- 1x detent_coupon_cam
- 2x detent_coupon_pin
- initially 1x detent_coupon_cassette_t18

If t18 does not reliably re-center, try t22, then t26.

Reject a variant if it shows whitening, excessive breakaway torque,
permanent set, rough stick-slip, or rapid wear.

This rig calibrates detent feel only. It is not a structural proof-load fixture.
