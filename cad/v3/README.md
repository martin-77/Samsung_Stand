# Samsung Stand v3

v3 extends the validated v2 rotating load path with modular outer guide rails.

Structural concept:
- INNER_ARM remains the vertical load carrier between rotor/root landing and the side glide track.
- OUTER_GUIDE plugs into the end of INNER_ARM with a 45-degree roof key.
- The same replaceable transverse PETG snap pin can retain the outer joint.
- OUTER_GUIDE has positive clearance to the fixed base and is intentionally not a normal vertical support.
- The U-shaped rail reaches beyond the reconstructed Samsung foot tip.

Current fit limitation:
- the U-channel is deliberately oversized (60 mm internal placeholder width).
- exact Samsung arm side/cross-section geometry still requires physical measurement.
- no claim is made that the placeholder channel is the final press/slide fit.

Suggested print quantities are stored in VALIDATION_v3_source.json.
