# V8 retainer fit coupons

Print these before the large v8 modules.

Three exact geometry families are included:
- base receiver + compact joint pin;
- 58 mm outer/saddle receiver + long outer pin;
- Ø25 mm pivot post + pivot cross-pin.

Acceptance:
- insert by hand without hammering;
- no crack or visible PETG whitening;
- barb snaps fully beyond the far wall;
- light manual pull does not release it;
- split legs can be compressed for non-destructive removal;
- no obvious permanent set after several insertion/removal cycles.

These coupons calibrate printed retention fit only. They do not replace the full assembly proof-load and cycling gates.
