# Samsung Stand v1

First validated structural CAD increment.

Included:
- three-piece 680 × 295 mm fixed base;
- two support-friendly 50 mm roof-key joints per side;
- replaceable PETG snap retainer pin;
- Ø150 / Ø80 mm annular swivel load path;
- central guide pilot plus removable PETG C-clip;
- rotor core prepared for later left/right saddle carriers.

Not included yet:
- final Samsung arm cross-section;
- INNER_LEFT / INNER_RIGHT saddle carriers;
- OUTER_GUIDE_LEFT / OUTER_GUIDE_RIGHT;
- final detent and ±15° stop mechanism.

The original Samsung stand outline in the preview is reconstructed reference geometry only, not manufacturing truth.
