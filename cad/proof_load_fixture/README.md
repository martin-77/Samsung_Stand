# V8 proof-load saddle pads

Print 2x proof_load_saddle_pad.

They seat in the two validated INNER_ARM saddle pockets and stand 3 mm
above the arm top plane. Place a rigid flat spreader board across both
pads so the test load enters at the real saddle stations.

Requirements:
- support the complete adapter on a rigid flat surrogate surface;
- do not use the Magnat Sounddeck as the 500 N proof support;
- the spreader must touch only the two proof pads;
- use a non-fragile substitute load, never the TV;
- test 500 N at center, -15 deg and +15 deg;
- additionally test each saddle branch alone at at least 250 N;
- follow docs/PHYSICAL_RELEASE_GATES.md for dwell, inspection and
  release criteria.

These pads are test tooling, not final Samsung contact parts.
